## 为什么摘掉

1. **与差异化冲突** —— 主产品的立身之本是"不玄学、看事实"，三观预审本质是尽调工具。
   同一个 App 里放占卜，会削弱唯一让它区别于其他交友软件的东西。
2. **来的人不是同一批** —— 塔罗吸引想要安慰的人（被动），三观预审吸引想高效筛人的人（主动）。
3. **没有增加实质信息** —— 塔罗和主产品的「恋爱分析」跑同一个引擎（`metrics.ts`）。
   塔罗多出来的只是洗牌动画和三个牌名。
4. **它最强的理由是营销理由** —— 小红书上塔罗内容有天然流量，但那是**渠道**价值，
   不必把占卜做进产品才能拿到。

## 解读接口

`Tarot.tsx` 只 `fetch('/api/tarot/reading')`，**客户端永远不持有 key**。
这个路由目前实现在 `vite.config.ts` 的 dev server 中间件里（`npm run dev` 可用）。
上线时用同样的逻辑起一个真实路由即可——它做的事只有三行：读 body、调
`generateTarotReading(question, cards, facts)`、返回 `{ text }`。

传给模型的 `facts` 就是「证据」屏上那几行，已经是「一条一句、不含推测」的形态，
prompt 里不再二次加工。证据为空时会明确要求模型直说「没有可用的事实」，不许推断。

## 指标口径

两条容易踩错、这里刻意定死的规则：

- **「谁开启对话」只算沉默后主动开口。** 上一条是对方说的，那这条无论隔了多久都是*回复*，
  不是开启。否则一个「隔 20 小时才回一句嗯」的人会被算成主动方，结论正好反过来。
- **回复间隔不剔除隔夜的长间隔。** 被晾着正是这里要看的东西。用中位数而不是均值，
  就是为了不让偶尔一两次长间隔带偏结论。

低于 20 条 / 跨度不足 3 天 / 有一方发言少于 5 条 → `sufficient: false`，界面直说「证据不足」。

这两条规则由 `metrics.test.ts` 锁住。典型反例：对方三次隔了一天多才回，
错误口径下会算出「40% 是你开启的」，正确口径是 100% —— 结论正好反过来。

## 抽牌为什么要用户自己点

原来是系统直接发三张给你翻。改成 13 张牌摊成扇形、自己挑——**仪式感来自选择，不来自等待**。
三个位置先空着摆出来，下一张要落到哪里是亮着的，所以「我抽到了什么」这件事有人参与。

弧宽按屏幕分两档（`wide`）：手机照桌面的角度扇会直接溢出屏幕。支点推到牌下方很远处，
弧才平、铺得开，每张露出可点的边；支点太近就会挤成一坨。

## 牌面的两条视觉规矩

- **逆位翻转整块，不只翻图。** 旧版只给 `<img>` 加 `rotate-180`，压暗的遮罩留在原地，
  于是画面倒过来、暗角还在下缘——看着像坏图。现在图和遮罩一起转。
- **缺插画的牌要有底图。** 55 张小阿卡纳还没出图，走 `TarotArt.tsx` 的线稿。
  线稿不能是透明底上一个光秃秃的符号，那摆在有插画的牌旁边完全不是一套。
  `GlyphPlate` 按母样式铺了夜空底、雨纹、云带、弦月和荧光绿小星芒。
  宫廷牌的剪影也照「无脸、瘦长、装饰艺术」重画过，`cards.test.tsx` 锁了同花色四个位阶不许重样。

## 尺寸为什么是响应式的

`TarotCard` 的 `md` / `lg` 两档在 `sm:`（640px）以下会收窄，依据只有一条：
**三张牌必须在一屏里并排**。

375px 手机减掉 `px-6` 的边距只剩 327px。三张 `lg` 若还是 188px，会竖着堆成 1404px，
「依次翻开三张」这个仪式要滚两屏才走得完——而手机正是这东西的主力形态。
收窄后文档高 812px，正好一屏。`sm:` 以上完全是原来的桌面尺寸，一像素没动。

改这两档的宽度时，记得同步 `Tarot.tsx` 里的 `gap-*` 和提示文案的 `max-w-*`，
它们会把列撑开，宽度不是只看牌本身。

## 牌面资产的正确用法

摘掉占卜 ≠ 浪费这 23 张插画：

- **小红书内容** —— 风格统一的牌面本身就是流量入口，而这正是塔罗最真实的价值
- **报告的情绪注脚** —— 恋爱分析里可放一张牌当视觉锚点（用牌的**意象**，不做牌的**预言**）
- **视觉体系** —— 深紫 `#2E0854` / 粉 `#FFB6C1` / 橙 `#FF8C00` / 荧光绿 `#CCFF00`
  这套四色油墨已被 78 张验证过能撑住

## 插画怎么继续生成

`npm run prompts` 会重新导出。`tarot-prompts.md` 里 78 条逐张提示词已经写好，母样式经 Canva Dream Lab 实测锁定。
小阿卡纳还缺 55 张（现在走 `TarotArt.tsx` 的几何线稿系统，风格自洽、可直接用）。

生成时的两条经验：
1. **绿色只做小星芒** —— 早期几张被"绿色闪电"吃掉了绿色额度，而闪电是「高塔」的专属符号。
   母样式已收紧：闪电只属于高塔，蛇只属于恋人/恶魔。
2. **人物一律无脸剪影** —— 脸是最不稳的部位，也正好呼应"统一、无名、无角色"的设定。
